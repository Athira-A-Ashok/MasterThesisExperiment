Create a Todo app using React and Vite where state management is handled through useReducer instead of scattered useState logic. The reducer should support three core actions: adding a task, deleting a task, and toggling completion status. Each task should have a structured format including a unique id, text content, completion boolean, and a timestamp. The UI should be broken into small reusable components, ensuring separation of concerns between form, list, and item rendering. Use React.memo for task items and memoize event handlers using useCallback to prevent unnecessary re-renders. Derived task views like filtered lists should be computed using useMemo rather than stored in state. Store all tasks using localStorage and ensure the app restores previous state on reload. Input validation should prevent empty adding and maintain a clean code.
