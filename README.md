# A Data-Driven Comparison of How Junior and Senior Developers Use Natural Language to Generate React Components




## 📌 Project Overview

This repository contains the complete experiment for a master thesis studying how junior and senior developers differ in writing natural language prompts for ChatGPT-based React code generation, and how those differences affect the quality of the generated code.

**150 developers** participated — 75 junior and 75 senior. Each submitted one natural language prompt for a React To-Do application via Google Form. The author submitted each prompt individually to ChatGPT, saved the generated code, and measured code quality using automated static analysis tools. All prompts, generated components, scripts, dataset, and analysis notebook are included.

## 📊 Understanding the experiment_data Folder

`dataset.csv` contains 150 rows — one per participant — with the following columns:

| Column | Description |
|---|---|
| `participant_id` | Assigned by the author for identification — J1 to J75 for juniors, S76 to S150 for seniors |
| `experience_level` | `junior` or `senior` |
| `years_experience` | Years of professional coding experience reported by participant |
| `prompt_length_chars` | Character length of the submitted prompt |
| `prompt_word_count` | Word count of the submitted prompt |
| `prompt_clarity` | Manual score 1–5 — how clearly the prompt communicates requirements |
| `prompt_specificity` | Manual score 1–5 — level of technical detail in the prompt |
| `prompt_structure` | Manual score 1–5 — how well the prompt is organised and structured |
| `ai_response_time_seconds` | Time in seconds for ChatGPT to generate the full response |
| `eslint_errors` | Number of ESLint linting violations in the generated component |
| `cyclomatic_complexity` | Cyclomatic complexity score of the generated component |
| `maintainability_index` | Maintainability index score (0–100, higher is better) |
| `readability_score` | Readability score (lower is better) |

## 🧪 Understanding the final_experiment Folder

This folder contains 150 subfolders, one for each participant. Junior participants are labelled J1 to J75 and senior participants are labelled S76 to S150. Each subfolder holds the participant's original prompt in prompt.txt, the React component generated by ChatGPT in App.jsx, along with any additional supporting files produced during the experiment.

## ⚙️ Understanding the final_metrics Folder

### `run_all_metrics.cjs`

This is a **Node.js script** that calculates all four code quality metrics for every generated React component. It is the script that produced all code quality values.

When executed, it loops through all 150 participant folders in `final_experiment/`, reads each `App.jsx` file, and computes the following for each component:

- **ESLint Error Count** — linting violations detected using the rules in `eslint.config.js`
- **Cyclomatic Complexity (CC)** — number of independent logical paths through the component
- **Maintainability Index (MI)** — composite score from 0 to 100; higher means more maintainable
- **Readability Score (RS)** — heuristic score based on naming, comments, and structure; lower means more readable

## 🚀 Getting Started — Running the Metrics Locally

### Prerequisites

- **Node.js v20.x or higher** — [Download here](https://nodejs.org/)

### Steps

**1. Clone the repository and switch to the branch**

```bash
git clone https://github.com/Athira-A-Ashok/MasterThesisExperiment.git
cd MasterThesisExperiment
git checkout master-thesis-dev
```

**2. Install dependencies**

```bash
npm install
```

**3. Run the metric calculation script**

```bash
node final_metrics/run_all_metrics.cjs
```

### Verifying Individual Prompt Length and Word Count

To verify the character count of any individual prompt on **Windows PowerShell**:

```powershell
(Get-Content "final_experiment/J1/prompt.txt" -Raw).Length
```

To verify the word count:

```powershell
(Get-Content "final_experiment/J1/prompt.txt" -Raw).Split().Count
```

## 📓 Running the Statistical Analysis

The full statistical analysis is in `notebooks/Master_Theseis_Experiment.ipynb`.

### Google Colab

Open the link below, upload `experiment_data/dataset.csv` when prompted, then click **Runtime → Run all**.

🔗 [Open Notebook in Google Colab](https://colab.research.google.com/drive/11yezXLxWepHLPoFvPH2h6DRJFcJ1-tJD?usp=sharing)


### What the Notebook Produces

Running all cells reproduces the following:

| Output | Description |
|---|---|
| Descriptive statistics | Mean, SD, min, max for all variables by group |
| Bar charts | Group comparisons for all prompt and code quality variables |
| Welch's t-test results | t-statistic and p-value for all 10 variables |
| Cohen's d effect sizes | Practical significance for all 10 variables |
| Shapiro-Wilk normality tests | Normality check for all variables in both groups |
| Correlation heatmap | Correlations across all 9 variables |
| K-means PCA scatter plots | Cluster assignments vs. actual experience level side by side |
| Elbow method chart | Inertia values for k=2 to k=7 |
| Efficiency metric chart | Maintainability index per second of AI response time |
